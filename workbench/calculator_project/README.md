# Calculator Project

A simple Python calculator project with unit tests.

## Structure
- `calculator.py` — Core calculator functions (add, subtract, multiply, divide).
- `test_calculator.py` — Unit tests for the calculator module.

## Usage
```python
from calculator import add, subtract, multiply, divide

print(add(2, 3))        # 5
print(divide(10, 2))    # 5.0
```

## Running Tests
```bash
python -m unittest test_calculator.py
```
